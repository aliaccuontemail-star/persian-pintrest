# Bumo Android

اپ اندروید Bumo با Kotlin/Compose، احراز هویت، فید، جستجو، ساخت پین، ذخیره در بورد، اعلان و تنظیمات.

## ساخت

```powershell
.\build-apk.ps1
```

APK در `output/bumo.apk` قرار می‌گیرد.

## نکته Gradle

این پروژه Gradle Kotlin DSL است. روی Windows با Android Studio جدید یا Gradle 9.6+ قابل build است.
